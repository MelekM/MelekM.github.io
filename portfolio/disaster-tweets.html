Disaster Tweet NLP Classification

This project classifies short social-media posts related to real disasters, combining classic text preprocessing with recurrent and transformer-era experimentation in a benchmark-style workflow.

Project Goals

  • Clean and normalize short, noisy social text for downstream modeling.
  • Compare sequence-based and transformer-informed approaches on the same classification problem.
  • Treat the work as a practical benchmark exercise with measurable submission performance.

Approach

Preprocessing: The workflow includes tokenization, stop-word removal, lemmatization, and normalization for tweet-length text.

Modeling: The notebook experiments with LSTM-based sequence models and also brings in BERT-related tooling to explore stronger language representations.

Evaluation: Performance is tracked through benchmark submissions rather than only notebook-local metrics.

Technologies and Tools Used

Languages/Technologies: Python, natural language processing, text classification

Libraries: TensorFlow, Keras, NLTK, spaCy, transformer tooling

Focus Areas: short-text modeling, sequence learning, benchmark evaluation

Key Results

  • Built an end-to-end NLP pipeline for noisy short-form social text.
  • Compared multiple modeling styles instead of anchoring on a single architecture.
  • The notebook records a best Kaggle submission score of 0.77290, which makes it a strong public-benchmark NLP example in the portfolio.
