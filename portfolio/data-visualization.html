Data Visualization Studies and Interactive Storytelling

This portfolio entry groups together a set of visualization projects focused on temporal, categorical, and hierarchical data. The work spans notebook-driven exploration and web-based presentation, with an emphasis on turning analysis into visuals that are easier to interpret and communicate.

Project Goals

  • Explore multiple visualization strategies for different data structures rather than forcing one chart style onto every problem.
  • Practice designing visuals that support comparison, hierarchy, and change over time.
  • Connect analysis with storytelling so the final output communicates more than just raw numbers.

Areas of Focus

Temporal data: Examining how values change over time and how pacing, scale, and trend emphasis affect interpretation.

Categorical data: Comparing groups clearly while reducing clutter and keeping labels legible.

Hierarchical data: Structuring nested information so relationships remain understandable at multiple levels.

Interactive storytelling: Organizing visuals into a narrative flow so users can move from exploration to explanation.

Technologies and Tools Used

Languages/Technologies: Python, HTML, notebook workflows, interactive visualization techniques

Focus Areas: exploratory analysis, visual design, interactive presentation, narrative structure

Key Results

  • Built a broader visualization portfolio across several data types instead of treating visualization as a single project style.
  • Developed stronger judgment around matching chart forms to the structure of the data.
  • Added a communication-focused layer to the portfolio that complements the more modeling-heavy projects.
