License Plate Recognition using Computer Vision and OCR

This project explores an Automatic License Plate Recognition pipeline that combines object detection and optical character recognition to locate vehicle plates and extract text from them under varied imaging conditions.

Project Goals

  • Detect license plates reliably across different framing, lighting, and background conditions.
  • Extract plate text from detected regions with a practical OCR workflow.
  • Build a modular computer-vision pipeline that separates detection, cropping, and text recognition.

Challenges and Solutions

Challenge: Plates vary in size, angle, contrast, and formatting, which makes end-to-end recognition noisy.

Solution: The project uses a staged pipeline where object detection first isolates the plate region and OCR is then applied to a smaller, more relevant crop.

Challenge: OCR quality falls quickly when detection crops are poor or images are low-light.

Solution: The workflow emphasizes better localization and preprocessing rather than treating OCR as a standalone step.

Technologies and Tools Used

Languages/Technologies: Python, computer vision, optical character recognition

Libraries: OpenCV, EasyOCR, YOLOv8

Approach: Detection-first ALPR pipeline with post-detection text extraction

Key Results

  • Created a workable ALPR prototype that links object detection and OCR into one recognition flow.
  • Demonstrated how model choice and crop quality directly affect downstream OCR accuracy.
  • Produced a strong applied computer-vision case study with real-world constraints rather than idealized input data.
