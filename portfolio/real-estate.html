The Multifamily Real Estate Development Process: An Optimization Approach to Development Evaluation

This project presents an optimization framework for evaluating multifamily development opportunities. Using property and contextual data, the goal was to estimate development feasibility and predict the number of units likely to be approved in a real planning environment.

Project Goals

  • Build a decision-support tool for evaluating multifamily development potential.
  • Use historical and contextual property features to estimate likely approval outcomes.
  • Combine predictive analysis with optimization thinking to support early-stage feasibility work.

Challenges and Solutions

Challenge: Development feasibility is shaped by many interacting constraints, including location, surrounding properties, and approval behavior.

Solution: The project frames the problem analytically by identifying influential features and translating them into a predictive optimization workflow.

Challenge: Real estate decisions are often high-stakes and uncertain, which makes interpretability important.

Solution: The approach emphasizes explainable inputs and a structured evaluation process rather than black-box prediction alone.

Technologies and Tools Used

Languages/Technologies: Python, optimization, predictive modeling

Libraries: Scikit-Learn, linear programming tooling, data analysis libraries

Focus Areas: feasibility analysis, land-use decision support, structured optimization

Key Results

  • Produced an optimization-oriented framework for evaluating multifamily development scenarios.
  • Showed how predictive modeling can support a business problem outside the more typical ML showcase domains.
  • Added a strong operations-and-decision-science project to the portfolio.
