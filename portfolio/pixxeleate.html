Pixxeleate Platform Backend

Pixxeleate is a private backend for an image-to-canvas platform that converts uploaded customer images into palette-constrained paint-by-dots previews and print-safe guides. The project combines API design, image processing, cloud-ready deployment, and internal operational tooling in one Django-based service.

Project Goals

  • Accept uploaded images and storefront preview requests through a clean backend API.
  • Generate deterministic previews and printable guides based on palette, canvas size, and rendering settings.
  • Support operational review through a browser dashboard for manual runs, palette management, and recent job inspection.
  • Keep the same core pipeline usable in local development and cloud deployment environments.

System Architecture

The application is built on Django and Django REST Framework, with an image-processing engine split into focused modules for loading, resizing, palette mapping, dot-plan generation, preview rendering, and guide rendering. That separation keeps the processing pipeline easier to test and evolve without tightly coupling business logic to HTTP views.

The backend also includes storage and metadata adapters so jobs can run against local files during development or cloud-backed services in deployment. A browser dashboard exposes manual processing controls, palette and guide-style management, and recent job inspection for faster iteration and debugging.

Challenges and Solutions

Challenge: Balancing interactive preview speed with print-safe output quality.

Solution: The pipeline separates lightweight preview generation from higher-fidelity printable output, while still using a shared processing core so both paths remain consistent.

Challenge: Supporting both local testing and cloud deployment without rewriting storage logic.

Solution: The backend uses adapter-style publishing and metadata layers, allowing the same processing request flow to target local files or cloud services.

Challenge: Handling event-driven order processing safely.

Solution: The service validates inbound requests, normalizes payloads, and stores order state idempotently before triggering downstream processing steps.

Technologies and Tools Used

Languages/Technologies: Python, Django, Django REST Framework

Infrastructure: PostgreSQL, SQLite, Firestore, Google Cloud Storage, Cloud Run

Image Processing: Pillow, pillow-heif, custom palette mapping and guide rendering modules

Other Tools: Docker, internal dashboard tooling, webhook-driven integrations

Key Results

  • Delivered an MVP backend that supports upload-to-preview processing, dashboard-based testing, and order-oriented job tracking.
  • Established a reusable processing core with clear seams between API endpoints, rendering logic, storage, and metadata persistence.
  • Created a deployment path that supports both local development workflows and cloud-hosted operation without duplicating the pipeline.
