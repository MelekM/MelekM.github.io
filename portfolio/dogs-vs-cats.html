Dogs vs. Cats Computer Vision Classification

This project applies convolutional neural networks to a binary image-classification problem, using multiple model variants and image-processing choices to distinguish between dog and cat images.

Project Goals

  • Build a reliable deep-learning pipeline for binary image classification.
  • Compare model variants instead of relying on a single architecture pass.
  • Practice the full workflow from image resizing and normalization through evaluation and submission formatting.

Approach

Data pipeline: The project uses image loading, rescaling, and generator-based training workflows to make large image data more manageable.

Modeling: Multiple CNN configurations were explored, including different layer depths and training setups.

Evaluation: The notebook records model performance directly and treats the project as an iterative benchmark exercise rather than a one-shot run.

Technologies and Tools Used

Languages/Technologies: Python, deep learning, image classification

Libraries: TensorFlow, Keras, ImageDataGenerator

Focus Areas: CNN design, image preprocessing, model iteration

Key Results

  • Built a complete CNN-based image-classification workflow from preprocessing through submission export.
  • Documented several model attempts instead of presenting only a final result.
  • One evaluated notebook run reports about 92.01% accuracy, making this one of the stronger deep-learning examples in the portfolio.
