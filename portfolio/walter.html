Walter Chemistry Chatbot

Project Goals

  • Design a chatbot that can respond to chemistry-related questions more effectively than a generic bot.
  • Connect NLP logic to a usable application flow.
  • Explore how domain framing improves response quality for educational and research-oriented use cases.

Why Narrow Domain Matters

General chat systems often struggle with specialized terminology and intent. Walter narrows the problem space to chemistry topics, making the assistant easier to reason about and evaluate.

Technical Shape

The project pairs NLP experimentation with a lightweight web application stack, so the assistant can be tested as an interactive tool rather than only a notebook artifact.

The result is a more product-oriented AI project that sits between model work and user experience.

What It Shows

  • Applied NLP in an educational setting.
  • Domain-specific chatbot framing.
  • Ability to connect model logic with a simple user-facing application layer.
