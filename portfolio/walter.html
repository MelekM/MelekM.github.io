Walter Chemistry Chatbot

Walter is a chemistry-oriented chatbot built to support subject-specific question answering and conversational assistance. The project focuses on making a narrow-domain assistant more useful by combining natural language processing with a simple application layer for user interaction.

Project Goals

  • Design a chatbot that can respond to chemistry-related questions more effectively than a generic conversational bot.
  • Build an application flow that connects NLP logic to a usable front-end service layer.
  • Explore how domain framing improves response quality for educational and research-oriented use cases.

Challenges and Solutions

Challenge: General-purpose chat systems often struggle with specialized terminology and domain-specific intent.

Solution: Walter narrows the problem space to chemistry topics and structures the interaction around that domain instead of aiming for broad open-ended conversation.

Challenge: Building a chatbot involves more than language modeling; it also needs application logic and a clear request/response path.

Solution: The project pairs NLP work with a lightweight web application stack so the assistant can be tested as a real user-facing tool.

Technologies and Tools Used

Languages/Technologies: Python, conversational AI, natural language processing

Libraries: TensorFlow, NLTK, Flask

Focus Areas: domain-specific Q&A, chatbot interaction design, applied NLP

Key Results

  • Created a domain-specific chatbot concept centered on chemistry support.
  • Demonstrated an applied NLP workflow that connects training logic to an actual interactive interface.
  • Added a more product-oriented AI project to the portfolio alongside modeling and analytics work.
